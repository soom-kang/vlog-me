# 하우스 스타일: 감성 95 · 예능 5 프리미엄 브이로그

2026-10-23 사용자가 베트남 본편 render v3(`work/prod-20261020-053818-932c04b5/render/v3/final.mp4`)를 보고 "현재 영상 세팅이 좋다"고 확정한 방식입니다. 다른 영상도 따로 지시가 없으면 이 방식으로 편집합니다. 제작 prompt나 brief가 다르게 말하면 그쪽이 우선합니다. 세부 규칙의 원본은 [자막 가이드](caption-style.md), [사운드 가이드](sound-guide.md), `renderer/src/production/presets.json`입니다.

레퍼런스는 오눅·걍민경 채널입니다. 사용자가 둔 로컬 파일 `refers/*.mp4`는 Git에서 제외되며 읽기만 합니다.

## 1. 한 줄 요약

화면 중심에 출연자가 있고 다른 목소리 없이 카메라를 보고 혼자 말할 때만 목소리를 살립니다. 그 밖의 모든 장면은 **풍경과 BGM, 감성 구어체 자막**으로만 이야기를 전합니다.

## 2. 비율과 길이

- 자막 비율 목표는 **감성 95 · 예능 5**입니다(`target_mood_share` 0.95, 권장 범위 85–100%). 시간 quota가 아니라 방향입니다. 실제로 웃긴 순간이 있을 때만 예능 자막을 넣고, 비율을 맞추려고 억지로 넣거나 빼지 않습니다.
- 길이는 정해 두지 않습니다. 쓸 수 있는 장면에 맞춰 정합니다. 사용자가 원하는 길이를 말하면 그만큼 채울 수 있는지를 원본 기준으로 먼저 보고합니다(베트남 본편: 목표 10분, 결과 9분 19초).

## 3. 후보 고르기

- **풍경 b-roll을 충분히 넣습니다.** 하늘, 정원, 물길, 수영장, 바다, 노을, 야자수 실루엣, 불 켜진 밤 풍경, 음식 클로즈업, 간판·장소 컷처럼 브이로그에 흔히 나오는 장면들입니다. 자막 없이 숨 고르는 컷도 넣습니다.
- 시간 순서로 장(아침, 점심, 오후, 노을, 밤, 마무리)을 나누고, 가장 아름다운 컷 하나를 콜드 오픈으로 맨 앞에 둡니다. 엔딩 뒤 쿠키 영상은 가볍게 둘 수 있습니다.
- 출연자 외 인물(동행)은 모습·목소리·손·옷·암시까지 모두 뺍니다. 프레임은 0.5초 간격으로 확인하고, 모자·옷처럼 헷갈리는 단서는 원본 사진으로 대조합니다.
- 두 사람의 대화가 겹치는 장면도 화면에 출연자만 보이는 구간이면 쓸 수 있습니다. 원음은 끄고 BGM만 깔며, 대화 내용은 혼자 말하듯 요약 자막으로 씁니다(4절).

## 4. 목소리와 원음

| 장면 | 원음 | BGM |
| --- | --- | --- |
| 출연자가 카메라를 보고 혼자 말함(셀카·토크), 다른 목소리 없음 | **원음 전체**(`original_gain_db: 0`): 목소리와 현장음 | **없음**(`"bgm": "말하는 동안 BGM 없음"`). 다음 장면에서 다시 시작 |
| 풍경·주변을 비추는 중 들어간 출연자 말소리 | 끔(`-80`) | 있음. 말한 내용은 감성 자막으로 옮김 |
| 두 사람 대화가 겹침 | 끔(`-80`) | 있음. 혼자 말하듯 요약 자막 |
| 대사 없는 풍경 | 끔(`-80`) | 있음 |
| 엔딩 뒤 쿠키 | `dialogue_only` | 목소리 아래에 BGM을 깔아도 됨 |

- 말하는 장면에 BGM을 깔고 문장 사이 pause마다 볼륨이 오르내리게(ducking) 하지 않습니다. 말하는 장면은 통째로 BGM을 뺍니다. 장면 경계에서는 조립 시 0.5초 페이드가 들어갑니다.
- 남성 음역 경고(`voices.py`)가 있는 구간은 `mute`로 끄거나 컷에서 뺍니다. 경고가 없어도 사람이 들어서 확인해야 합니다.

## 5. 자막

- preset 기본값은 레퍼런스형입니다. 대사는 `talk`, 내레이션은 `talk-note`, 짧은 감성 한 줄은 `talk-mood`, 장소는 `place-tiny`(왼쪽 위, sub에 영문과 시간)입니다. 리뷰에 같은 preset 반복 경고가 떠도 일관된 자막 모양을 위한 것이므로 그대로 둡니다.
- 말투는 20–30대 여성이 직접 말하는 구어체입니다. 끝맺음은 `~어요`, `~더라구요`, `..`, `!`, `?`이고, 혼잣말은 괄호로 씁니다. 문어체 일기투(`~했다`, `~였다`)는 쓰지 않습니다.
- 감수성은 장면에서 출발합니다. 화면에 보이는 것과 출연자가 실제로 한 말을 근거로 쓰고, 확인되지 않은 감정·사건은 쓰지 않습니다. 실제로 말하지 않은 문장은 `narration`입니다.
- 동행을 암시하는 말(`우리`, `같이`, `오빠`, 누군가에게 묻는 말투)은 쓰지 않습니다.
- 예능은 5% 안팎입니다. `deadpan`·`pen-note`·`bracket` 한 줄, 리액션 한 단어 `pop-word`(영상 전체에서 1–4번)만 씁니다. 사용자가 고른 개그 문구는 유지합니다.
- 내레이션 읽기 시간 공식과 줄 제한은 [자막 가이드](caption-style.md)를 따릅니다.

| 쓰지 않음 | 씀 |
| --- | --- |
| `오일은 직접 고를 수 있었다 / 코코넛으로 정했다` | `오일은 직접 고를 수 있어요 / 망고 vs 코코넛.. / 저는 코코넛으로!` |
| `해가 지는 데 20분쯤 / 그렇게 밤이 왔다` | `해 지는 거 진짜 순식간이에요 / 한 20분?` |
| `우리는 좋은 대화를 나눴다` | `(칵테일 토크.. / 한 잔에 만오천 원 정도인데 / 이 뷰면 괜찮다는 결론)` |

## 6. BGM과 효과음

- **차분하고 감수성 있는 곡만** 씁니다. 장마다 한 곡을 쓰고, 장이 곡 길이를 넘지 않게 나눕니다. 밝은 우쿨렐레·코믹 곡은 쿠키나 예외 장면에만 씁니다.
- 등록된 차분한 곡은 Slow Pop, Chillax, Forest Mist Whispers, Sunset Dream, Old Letter, Serene View입니다. 베트남 본편 배치(아침 → 밤 순서)를 기본 순서로 참고합니다. 새 곡이 필요하면 `audio_search`로 Mixkit 감성곡 후보 표를 만들고, 사용자가 곡별로 승인한 뒤에만 받습니다([사운드 가이드](sound-guide.md)).
- **음량:** 곡마다 원래 음량이 달라서 `gain_db = -27 - (곡의 integrated LUFS)`로 맞춥니다(`config/media-licenses.json`의 `integrated_lufs`). 최종 렌더는 -14 LUFS로 정규화됩니다.
- 같은 곡을 이어 쓰는 후보는 `bgm.offset`으로 이어 재생합니다.
- 효과음은 거의 쓰지 않습니다. 셔터 연사(사진 개그)와 바람 소리 정도만 쓰고, 만화풍 효과음(boing, pop, 휘슬, 드럼)은 쓰지 않습니다.

## 7. 화면 톤과 전환

- `look`: `warm 0.5 · grain 0.08 · vignette 0.2 · letterbox 없음`
- `light_leak`: 오프닝과 저녁 장 시작에 1번씩
- `dissolve`: 장소·시간이 바뀌는 첫 컷. 원본 여유가 부족하면 조립이 컷으로 바꿉니다.
- `drift`: 고정된 풍경 영상. 사진에는 쓰지 않습니다.
- 확대·속도선 같은 예능 효과는 쓰지 않습니다. 필요하면 흔들기 1번 정도만 씁니다.

## 8. 진행 순서

`/vlog-workflow`를 따릅니다. 이 스타일에서 특히 지키는 확인 지점은 다음과 같습니다.

1. 후보 리뷰(기대 화면과 미리보기)에서 사용자의 채택, 제외, 자막 수정을 받습니다.
2. 기록(`review.py select`) → 조립(`assemble.py`) → `--check` → 렌더(`production_render` 동의 후)
3. 렌더 뒤 프레임 몇 장으로 자막 가독성을 확인하고, `production_render`를 다시 `false`로 돌립니다.
4. 사람의 시청·청취 확인은 PASS로 대신하지 않고 따로 보고합니다.
