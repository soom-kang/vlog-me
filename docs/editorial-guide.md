# 편집과 사운드 기준

다음 제작에서 사용할 판단 지침입니다. 실제 미디어로 검증한 취향 preset은 아직 없습니다.

## Brief와 길이

유형·핵심 이야기·톤은 매 제작 프롬프트에서 정합니다. 여행·일상·과정·혼합 유형에 같은 harness를 사용합니다. 예쁜 구도와 예능 자막, 재미 60%·감성 40%는 사용자 취향 참고값이며 현재 brief가 우선합니다. 60:40을 시간 quota로 바꾸지 않습니다. 길이와 편수는 이야기·유효 장면으로 제안하며 길다는 이유로 필수 맥락을 삭제하지 않습니다.

## 선별과 Caption

관찰한 대사·동작·시각 근거와 편집자의 해석을 구분합니다. 웃음은 setup·payoff·reaction을 함께 보고 현장음·쉼을 기계적으로 제거하지 않습니다. 후보가 없는 구간도 예산 내에서 재검토합니다. 한 장의 frame이나 ASR만으로 전체 행동·감정을 확정하지 않습니다.

대사 자막은 발화에 연결하고 예능 코멘트는 `editorial`로 구분합니다. 밀도·위치·가독성은 같은 장면 비교 후 사용자와 확인합니다. 현재 synthetic caption은 연결 검사용이며 최종 예능 스타일이 아닙니다.

## 풍부한 무료 사운드

장면별 BGM 전환·짧은 강조음·현장음·쉼을 조합합니다. 매 컷의 효과음이나 큰 음량을 목표로 삼지 않습니다. 대사 중에는 BGM을 낮추고 타이밍·반복 피로·fade/loop 경계를 청취합니다. 실제 없었던 사건의 소리를 원음처럼 표시하지 않습니다.

세 플랫폼 이용 권한, claim 관련 근거, 실제 플랫폼 검사 결과를 분리합니다. 무료·무표기만으로 안전하다고 판단하지 않습니다. 초기에는 사용 권한과 미등록/별도 해제 불필요 근거가 확인된 후보만 선택하고 `unknown`은 보류합니다. 실제 후보 수는 미확인입니다. 원음의 카페·TV·공연 음악도 별도로 확인합니다.

상세 채택 gate와 공식 출처는 [설계 8절](superpowers/specs/2026-10-18-vlog-environment-design.md#세-플랫폼-공통-선별-기준)에 있습니다. 실제 사용 asset만 credit에 기록하고 교체하면 preview·QA·출처·관찰 결과를 갱신합니다. 음원 다운로드·권리 사실 확인·platform 검사는 현재 실행 기능이 아닙니다.

## 완료의 근거

같은 영상/자막에 사운드만 바꿔 비교하고 다른 장면에도 적용합니다. 수치 측정과 사람의 시청·청취는 별도 결과입니다. 영구 무claim 보증, synthetic 성공에 의한 취향 승인, 다른 run으로의 자동 승인을 하지 않습니다.
